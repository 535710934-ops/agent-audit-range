What this is

An open benchmark range and zero-dependency audit toolkit for the deployment and permission layer of AI agents and MCP servers — where tools execute, credentials live, and context gets poisoned. I audit what the model layer can't see: leaks, over-granted tools, unsafe defaults, session handling, CORS, error disclosure.

Not a scanner marketing page, and not model-side red teaming — that layer already has excellent free tools (promptfoo, garak, PyRIT, AgentDojo).

  • Two protocol-true target groups (JSON-RPC 2.0 / Streamable HTTP) — seeded flaws mirror 2025–2026 wild incidents: tool-description injection, unscoped SQL/shell tools, error stack leaks, predictable sessions, missing auth
  • Passive observation only: no tool execution against targets, no internal access, no state changes
  • Built-in authorization gate: every target requires a declared authorization (self / ctf / bounty / written) or the tool refuses to run
  • For enterprises: a read-only shadow-agent inventory — a complete list of the agents, MCP clients and tools already touching your data, and what each one can reach. No agent is executed, no business data is read.

What I cannot prove (read this first)

  • Reverse-mapping three real CVSS 9.x incidents with all 16 checks: 1/16, 1/16, 0/16. Semantic paraphrase dropped detection from 75% to 0%. I publish this as a regression baseline because knowing how far I fall short is the only honest way to improve.
  • An audit report is not a security verdict and not a compliance certification. Untestable items are marked untested — SKIPPED never counts as PASS.
  • CVE numbers cited anywhere are taken from public sources and not independently verified.
